# Budget Project Presentation Layout

## Scope

ปรับ layout การแสดงรายละเอียดโครงการงบประมาณเพื่อใช้ประกอบการนำเสนอผู้บริหาร

## Layout

- คงแผน/ผลการดำเนินงานไว้เป็นส่วนแรก
- ย้ายรูปภาพประกอบมาอยู่ถัดจากความก้าวหน้า
- แสดงรูปทั้งหมดในกริด 3 คอลัมน์บนจอใหญ่, 2 คอลัมน์บนแท็บเล็ต, 1 คอลัมน์บนมือถือ
- ใช้ขนาดภาพและอัตราส่วนเดียวกัน เพื่อให้สแกนหลักฐานได้รวดเร็ว
- คลิกรูปเพื่อเปิดภาพขยายและคำอธิบายด้วย lightbox เดิม
- ย้ายปัญหา/อุปสรรคและข้อเสนอแนะลงมาหลังรูปภาพ
- ไม่มี scale/translate animation เมื่อชี้รูป

## Verification

- production build ผ่าน
- รูปขึ้นหลังความก้าวหน้าและก่อนปัญหา/ข้อเสนอแนะ
- ทุกรูปแสดงในกริดและคลิกขยายได้
