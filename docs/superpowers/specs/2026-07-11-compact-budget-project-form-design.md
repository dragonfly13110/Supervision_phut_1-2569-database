# Compact Budget Project Form

## Scope

ปรับเฉพาะ `SectionBudgetDetailed` สำหรับหน้าข้อมูลโครงการงบประมาณ โดยไม่กระทบหน้าอื่นและไม่แก้ข้อมูลเดิมใน JSON

## Changes

- ลบ UI “ประเด็นเน้นย้ำ (เลือกได้หลายข้อ)” และตัวเลือก 1–13 ออกจากฟอร์ม
- ลดระยะห่างภายในส่วนรายละเอียดและลดความสูงเริ่มต้นของช่องข้อความ เพื่อให้เลื่อนถึงส่วนรูปภาพเร็วขึ้น
- ยกเลิกการขยาย/ยกตัวเมื่อชี้เมาส์สำหรับการ์ดและรูปภาพในหน้านี้ แต่ยังคงสี hover ที่ช่วยบอกว่าคลิกได้
- ไม่ลบ field เดิมจากชนิดข้อมูลหรือไฟล์ JSON เพื่อไม่ให้ข้อมูลเก่าเสียหาย

## Verification

- production build ต้องผ่าน
- ตรวจว่า UI ไม่มีตัวเลือกประเด็นเน้นย้ำ
- ตรวจว่า hover ในหน้านี้ไม่เปลี่ยน `transform`
