# รูปภาพประกอบโครงการ — ครั้งที่ 2/2569

## เป้าหมาย

ให้ผู้ดูแลเพิ่มรูปภาพประกอบแต่ละโครงการในหน้ารายละเอียดงบประมาณของครั้งที่ 2/2569 ได้จากไฟล์ในเครื่อง (เลือกไฟล์หรือลากวาง) หรือ URL และพิมพ์คำอธิบายใต้รูปได้

## พฤติกรรม

- ผู้ใช้ที่ล็อกอินกด **แก้ไขข้อมูล** ก่อน จึงเห็นพื้นที่เพิ่มรูปภาพ
- การเพิ่มจากไฟล์รองรับ PNG, JPG และ JPEG; อัปโหลดไปที่ `public/project-images/<ชื่อโครงการ>/` ใน GitHub
- การเพิ่มจาก URL ใช้ URL นั้นโดยตรงและไม่คัดลอกรูปเข้าที่เก็บ
- หลังเพิ่มรูป ผู้ใช้พิมพ์หรือแก้ไขคำอธิบายใต้รูปในช่องข้อความของรูปนั้นได้
- กด **บันทึก** เพื่อบันทึกรายการรูปและคำอธิบายลง Google Sheets ของครั้งที่ 2/2569
- การลบรูปจะลบรายการรูปจากข้อมูลโครงการ; ไม่ลบไฟล์เก่าใน GitHub เพื่อให้การทำงานเรียบง่ายและไม่เสี่ยงลบผิดไฟล์

## ส่วนที่แก้

- `SectionBudgetDetailed.tsx`: ทำปุ่ม/พื้นที่เพิ่มรูปให้ชัดเจนในโหมดแก้ไข เพิ่มตัวเลือก URL และใช้ข้อมูลรูปแบบ `{ url, caption }` เดิม
- `api/upload-image.ts`: Vercel serverless endpoint สำหรับตรวจชนิดไฟล์และส่งไฟล์ไป GitHub Contents API โดยใช้ค่า environment variables ฝั่งเซิร์ฟเวอร์
- `vite.config.ts`: คง dev middleware ให้ทำงานแบบเดียวกันเมื่อรันในเครื่อง

## การตั้งค่าและข้อผิดพลาด

- เพิ่ม environment variables ฝั่ง Vercel: `GITHUB_TOKEN`, `GITHUB_OWNER`, `GITHUB_REPO`, และเลือก `GITHUB_BRANCH` (ค่าเริ่มต้น `main`)
- ถ้า token หรือการอัปโหลดล้มเหลว จะแจ้งข้อความผิดพลาดและไม่เพิ่มรายการรูป
- URL ว่างหรือไม่ใช่ `http/https` จะไม่อนุญาตให้เพิ่ม

## ตรวจสอบ

1. เข้าโหมดแก้ไขในครั้งที่ 2/2569 แล้วเลือกไฟล์/ลากไฟล์รูปและเห็นรูปใหม่พร้อมช่องคำอธิบาย
2. ใส่ URL รูปและคำอธิบายแล้วบันทึก จากนั้นรีเฟรชหน้าจอ ข้อมูลยังคงอยู่
3. ทดสอบไฟล์ที่ไม่ใช่รูปและ URL ที่ไม่ถูกต้อง ต้องถูกปฏิเสธ
